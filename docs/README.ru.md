# TxGate

[English](../README.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | **Русский** | [Português](README.pt.md)

Страж RPC вашего кошелька: проверяйте каждый запрос и одобряйте каждую транзакцию до её отправки в сеть.

TxGate — это настольное приложение (macOS, Windows, Linux), которое запускает локальный JSON-RPC эндпоинт Ethereum. Направьте кошелёк на TxGate вместо публичного RPC:

- **Запросы на чтение** (`eth_call`, `eth_getBalance`, …) пересылаются выбранному вами upstream и отображаются в реальном времени.
- **`eth_estimateGas`** выделяется: обычно это значит, что кошелёк вот-вот попросит вас подписать. TxGate декодирует вызов и отмечает рискованные паттерны.
- **Методы отправки** (`eth_sendRawTransaction`, `eth_sendRawTransactionSync`, `eth_sendRawTransactionConditional`, `eth_sendTransaction`, `eth_sendBundle`, `eth_sendPrivateTransaction`, `eth_sendPrivateRawTransaction`, `mev_sendBundle`, `personal_sendTransaction`, `eth_sendUserOperation`) **задерживаются**. Ничего не попадает в сеть, пока вы не одобрите транзакцию в TxGate.

Что показывает окно одобрения:

- Декодированную транзакцию: подписанта, получателя, функцию, аргументы и сумму.
- Отметки риска, например:
  - неограниченные разрешения
  - `setApprovalForAll`
  - вызовы Permit/Permit2
  - разрешения для аккаунтов без кода контракта
  - делегирование EIP-7702
  - несовпадение ID сети
  - пропуски nonce
- Сравнение с оценкой газа, которую кошелёк сделал ранее. Если они различаются, фронтенд dApp мог подменить транзакцию.
- Симулированные изменения балансов и разрешений, если настроен access key Tenderly.

Интерфейс, сообщения о рисках, предупреждения Safe и системные уведомления доступны на English, 简体中文, Español, Русский и Português. TxGate следует языку системы, пока вы не выберете язык в **Настройки → Язык**.

### Safe multisig

Safe перемещает средства одной транзакцией `execTransaction` в блокчейне после того, как владельцы подписали её вне сети. TxGate проверяет обе части (подробности в [SAFE.md](SAFE.md), на английском):

- **Задержанная `execTransaction`**: TxGate раскрывает транзакцию Safe, включая пакеты MultiSend, и выполняет обычные проверки для каждого внутреннего вызова. `DELEGATECALL` в любой контракт, кроме официальных MultiSend / SignMessageLib от Safe, помечается как опасный — именно так был захвачен Safe биржи Bybit. TxGate также читает Safe через ваш собственный upstream, вычисляет хеш для текущего nonce и проверяет каждую подпись по списку владельцев и порогу. Он отмечает неофициальную реализацию, включённые модули и вызовы самого Safe, меняющие владельцев, порог, guard, модули или fallback handler.
- **Задержанный `approveHash`**: TxGate находит хеш в Safe Transaction Service, пересчитывает его по возвращённым полям и показывает, что именно вы одобряете.
- **Перед подписью** (страница «Safe multisig»): вставьте типизированные данные EIP-712 или выберите транзакцию из очереди. TxGate декодирует её и показывает хеш домена, хеш сообщения и хеш транзакции Safe для сравнения с экраном аппаратного кошелька.
- **Отслеживаемые Safe**: TxGate периодически опрашивает каждый Safe и присылает системное уведомление, когда меняются владельцы, порог, реализация, guard, fallback handler или модули, а также когда кто-то предлагает новую транзакцию. Предложения из Transaction Service пересчитываются локально, поэтому подменённый сервис обнаруживается, а не принимается на веру.

## Ограничения

- Запросы подписи (`personal_sign`, `eth_signTypedData*`, включая Permit / Permit2 и подписи владельцев Safe) никогда не проходят через RPC, поэтому TxGate их не видит. Транзакции Safe проверяйте на странице «Safe multisig» перед подписью.
- Проверки Safe читают состояние контрактов через `eth_call`. Flashbots Protect (upstream по умолчанию для mainnet) не поддерживает `eth_call`, поэтому для их работы укажите для mainnet отдельный upstream для чтения.
- TxGate может только одобрить или отклонить транзакцию. Подписанную транзакцию изменить нельзя.
- При прослушивании `0.0.0.0` пока нет токена доступа. Любой в вашей локальной сети может использовать порт и стоящие за ним ключи провайдеров.
- Запросы с `Origin` обычного веб-сайта отклоняются, чтобы открытая вами страница не могла незаметно использовать эндпоинт. Расширения-кошельки, нативные кошельки и страницы на `localhost` разрешены (с CORS).

## Использование

1. Запустите TxGate. Он принимает подключения на `http://127.0.0.1:8545`.
2. В разделе **Сети** добавьте каждую сеть, которой пользуетесь. Mainnet уже настроен на Flashbots Protect (`https://rpc.flashbots.net`). Для сети можно задать отдельные upstream для *чтения* и *отправки*, а ключи Alchemy / Infura / Ankr / dRPC сохранить в **Настройках**, чтобы не вводить URL вручную. Там же находятся учётные данные Tenderly, адрес прослушивания и журналирование.
3. В кошельке укажите для сети RPC URL `http://127.0.0.1:8545/<chainId>`, например `/1` для mainnet или `/8453` для Base (работает и шестнадцатеричная запись, например `/0x2105`).

Когда кошелёк отправляет транзакцию, TxGate уведомляет вас и открывает окно одобрения. Если вы отклоните её, кошелёк получит ошибку JSON-RPC `4001`. Если кошелёк перестанет ждать, подписанная транзакция останется в очереди, и вы всё ещё сможете отправить её или отбросить.

Настройки, включая API-ключи в открытом виде, хранятся в `config.toml` в папке конфигурации приложения. Журнал запросов — это `txgate.sqlite` в папке данных приложения; он хранится бессрочно.

## Разработка

Требования: Rust (stable), Node.js 20+ и [необходимые компоненты Tauri](https://tauri.app/start/prerequisites/) для вашей ОС.

```sh
npm run setup        # установить Tauri CLI и зависимости UI
npm run dev          # запустить приложение с горячей перезагрузкой
npm run build        # собрать установщики в target/release/bundle
cargo test --workspace
```

Отправить запущенному экземпляру трафик, похожий на трафик кошелька:

```sh
npm run wallet:sim -- reads      # также: estimate | send | batch | all
```

`npm --prefix ui run dev` открывает UI в браузере с тестовыми данными — удобно для работы над вёрсткой.
